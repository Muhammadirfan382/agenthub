# Runtime dependencies (pinned). Justification:
#   fastapi            HTTP framework chosen for the backend
#   pydantic           request/response models and validation (FastAPI model layer)
#   pydantic-settings  environment-based configuration
#   uvicorn            ASGI server to run the app
#   sqlalchemy         database toolkit and async ORM
#   asyncpg            async PostgreSQL driver used in staging and production
#   alembic            versioned schema migrations
#   anthropic          official Anthropic SDK: the Claude adapter behind the model
#                      gateway (streaming, typed errors, retries). Server-side only.
#   openai             official OpenAI SDK: the OpenAI adapter behind the model
#                      gateway, used only when a tier is routed to openai:<model>.
#                      Both SDKs share httpx2, already used by the test suite.
#   prometheus-client  the official Prometheus client: /metrics in the standard
#                      exposition format, correct histograms and escaping.
#   opentelemetry-api / opentelemetry-sdk
#                      standard tracing: spans across API, runtime and gateways,
#                      and trace ids in every log line.
#   opentelemetry-exporter-otlp-proto-http
#                      sends spans to a collector, only when OTEL_EXPORTER_OTLP_ENDPOINT
#                      is set. Nothing is exported by default.
